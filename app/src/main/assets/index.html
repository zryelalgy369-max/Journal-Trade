Cadangan data

Data tersinkron ke akunmu dan juga tersimpan di browser ini. Export secara berkala sebagai cadangan tambahan, atau untuk memindahkan data ke tempat lain. Foto chart tersimpan di akunmu dan tidak ikut file cadangan.

Impor dari broker (MT4 / MT5)

MT4: buka Account History, klik kanan, pilih Save as Report (HTML). MT5: buka History, klik kanan, Report, simpan sebagai HTML. Bisa juga file CSV, atau salin barisnya dari tabel lalu tempel di bawah. Yang dibaca adalah transaksi yang sudah ditutup (tabel Positions di MT5).

Lupa kunci?

Kunci hanya berlaku di perangkat ini. Data jurnalmu tetap aman di akunmu. Kamu bisa membuka jurnal ini di perangkat lain, atau menghapus data situs halaman ini lewat pengaturan browser lalu masuk lagi. Datamu akan tersinkron kembali dari akun.
